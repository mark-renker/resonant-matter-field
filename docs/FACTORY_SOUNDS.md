# Factory sounds

RMF 1.0 includes 24 starting points. Each sound stores the underlying automatable parameters; the names describe the intended material or behavior rather than sampled source material.

## Core and struck bodies

- Kinetic Plate
- Sparse 19-EDO Metal
- Ceramic Rain
- Bone Chime
- Hollow Beam
- Shell Drops
- Wide Fracture

## Rubbed and adhesive contact

- Friction Cloud
- Adhesive Slip
- Graphite Drag
- Velvet Current

## Particulate fields

- Tritave Dust
- Ferrofluid Sand
- Static Flakes
- Cold Ash

## Electromechanical and active

- Active Coil Bloom
- Near Instability
- Magnetic Breather
- Voltage Flower

## Spatial and nodal

- Nodal Orbit
- Edge Pickups
- Center Null

## Tuned constellations

- Bohlen Pierce Constellation
- Just Bronze

Several sounds expect one of the supplied Scala files for their named lattice. Load the corresponding `.scl` file from the Tuning panel; the scale text is then embedded into host state.
